# 桌面托盘与退出行为

更新日期：2026-09-23。

## 当前规则

- 托盘弹窗版本来自原生运行程序的 `package_info().version`，不写固定版本号；浏览器演示使用 package.json 版本。
- 有可用托盘时，⌘Q 和系统菜单“退出”收起主窗口与托盘弹窗，保留进程及定时任务。这个行为独立于“关闭窗口后继续运行”开关；该开关只决定窗口关闭按钮的行为。
- 托盘弹窗内的 ⌘Q 同样进入后台，执行来源检查期间也允许收起；“完全退出”不再显示 ⌘Q 快捷键提示。
- 托盘中的“完全退出”结束程序，继续保留更新中、写文件中的退出保护。应用升级重启正常放行。
- 无可用托盘时不截留系统退出，避免隐藏后无法恢复主窗口。

## 实现与验证

Tauri 区分系统交互的 `ExitRequested { code: None }` 与程序主动退出/重启的 `Some(code)`。原先只保护忙碌任务，未拦截普通系统退出；现按上面规则处理。托盘图标由 Tauri 资源表持有，问题并非局部变量释放。
