# 分发来源切换

同名 Skill 的归集记录、Git 记录和本地引用保持独立身份。工具已经使用旧记录时，新的分发必须明确确认来源切换，不能因名称或内容相同自动替换。

## 用户路径

- Skill 库汇总多个来源的条目提供“选择来源分发”；批量分发也进入同一个预览流程。单独分发时可在 UI 库选择器中选择同名来源；预设和本地来源的成员由其配置决定。
- 先选目标，再预览。出现已有受管安装时，展示当前/新来源、实际实体路径、版本、Skill 目录内容是否一致（不包含包级共享资源）、现有引用及取消后的行为。
- 可以切换的条目在底部固定区提供默认不勾选的确认选项，勾选后重新生成计划；点击“确认执行”才修改链接。返回选择、关闭窗口或预览失败清空此次授权。
- 旧关系仅有手动引用、或当前正在应用的预设/来源引用时可切换。其他预设或本地来源仍引用旧记录时，显示具体名称并阻止切换；先通过对应管理页面解除其引用后再预览。
- 全局说明和错误固定在标题下，底部确认固定，只有来源对比列表滚动。

## 执行与生命周期

- `plan`、`distribute`、`apply_preset`、`apply_local_source` 接受 `replaceBindingIds`，默认空数组。它与 `takeover`（切换外部链接到库版本）和 `adoptExisting`（接管同实体软链删除权）相互独立。
- 返回的 `PlanItem.replacement` 包含旧绑定 ID、旧 Skill ID、旧新实体路径与版本、现有/阻塞引用、内容比较结果和是否保留原外部链接恢复语义。
- 只切换被明确选中的目标关系；保留原安装入口名称。多个同名旧入口无法唯一判定时拒绝自动选择。未知或已失效的绑定选择拒绝执行。
- 校验库版本、完整计划、当前软链及新中央快照。保留既有事务日志，通过 Change.before 校验实际链接，失败时回滚链接和状态。
- 切换复用绑定 ID，更新 Skill、版本和实体指向；现有手动引用保留，并登记当前分发引用；不迁移其他预设/来源引用。取消单个引用不会影响仍有其他引用的链接。
- 不删除旧 Skill、来源、统一库实体或归集备份；其他工具的链接不变。新 Git 来源更新不会继续作用于已切走的旧绑定。
- 原本仅复用的外部链接在切换时保存原指向，最后取消时恢复；原本受管且无恢复指向的链接在最后取消时移除，原实体始终保留。
- 自动更新、本地来源重扫和包同步不带来源切换授权；遇到跨来源冲突保持原安装。

## 验证

隔离集成测试覆盖真实归集、本地/Git 导入、同名内容一致或不同、非标准旧目录名、当前预设成员替换、其他预设/本地来源阻塞、撤销恢复、版本过期、未知绑定、外部修改和批量原子性。浏览器使用模拟数据验证来源选择、旧新详情、默认拦截、勾选重预览、返回重置授权及共享引用提示。真实用户安装未执行切换。
