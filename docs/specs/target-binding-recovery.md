# 重新添加分发目标时自动恢复绑定

删除目标仍然保留目标目录及其中的文件。重新添加该目录时，自动扫描直接子级软链接，恢复可以准确识别的统一库分发绑定，无需额外确认。

## 识别规则

- 链接必须有效，目标包含 `SKILL.md`，且精确指向已知 Skill 的统一库快照成员路径。
- 匹配候选来自当前 Skill、预设锁定版本及其他目标的现有绑定；Skill 身份必须仍在库中。
- 同一实体对应多个 Skill 身份或版本信息有歧义时跳过，不按名称猜测。
- 整个快照须通过现有完整性校验。同一快照在一次添加过程中只校验一次。
- 外部链接、普通目录、失效链接、无法匹配的旧快照、被修改的快照保持原样。

## 恢复结果

- 创建属于新目标 ID 的绑定，保留实际快照的版本，列表直接显示已分发。
- 归属为手动分发，关闭跟随更新；已删除的预设归属和原外部链接恢复信息无法从目录推断，不重建。
- 相对链接通过现有事务机制转换为指向同一实体的绝对链接，以兼容后续取消、更新与迁移校验。
- 不重写 Skill 内容、不自动升级版本。取消恢复后的手动分发会移除对应链接。
- 仅在添加目标时执行；已经重新添加的目标需使用新版重新移除并添加。普通刷新不接管文件。

## 验证

通过隔离配置目录调用真实 CLI API，验证删除后文件保留、重加使用新目标 ID 自动绑定、相对链接恢复、取消分发，以及外部链接、失效链接、普通目录和被修改快照不被接管。
