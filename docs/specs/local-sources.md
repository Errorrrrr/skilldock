# 本地来源配置与分发

本地来源通过侧栏或发现与安装进入。用户提供名称和原始目录，扫描后确认成员；内容直接引用原目录，不复制、不执行 Git pull、不建立定时任务。现有复制导入入口保留，二者文案明确区分。

配置保存后返回列表；同目录重复添加复用配置和成员，重叠来源引用同一实体时共享成员身份。已有同名但不同实体的 Skill 保持独立并在分发时提示冲突。

列表支持筛选、分页、整体分发、按目标取消、配置重扫。分发复用实际计划预览；已有同实体软链默认复用并保留；用户可在预览中选择接管管理。新建或已接管软链仅在没有其他来源/预设/手动引用时删除，实体目录保留。来源引用独立记录，不需要创建隐藏预设。

修改目录需要另加来源；配置编辑保留目录，避免直接破坏原链接。重新扫描默认保留已有选择，新成员待确认纳入；未扫描到的成员展示名称，保存时撤销该来源引用，其他引用保留。重扫后仅同步该来源已经分发的目标。同名冲突时整个保存事务回滚。

取消和移除必须确认范围；移除配置仅取消该来源引用并隐藏配置，保留实体和库记录。所有写操作带库版本校验。扫描/保存过程中禁用重复提交和关闭；错误留在弹窗内可重新扫描重试。框架固定，仅表格、成员列表和弹窗内容滚动。
