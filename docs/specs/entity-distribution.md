# 按实体区分分发候选

同名 Skill 的多条来源记录不等于多个版本。列表保留来源记录用于追溯，分发选择按记录实际指向的实体去重。

## 行为

- 同一实体：显示“多条来源记录 · 同一实体”，隐藏“选择实体分发”；点击未分发的工具直接分发，批量弹窗不显示重复来源候选。
- 不同实体：显示分发候选数量和“选择实体分发”；点击未分发工具进入选择弹窗，并自动选中该目标。
- 已分发工具仍按原有规则取消手动分发；预设、来源引用及外部链接的保护规则保留。
- 不合并或删除 Skill、Source、Binding、快照和来源记录；不按名称、版本文字或单文件内容推断实体相同。

## 实体识别

`Snapshot.skillEntityPaths?: Record<string, string>` 为新增兼容字段，映射 Skill ID 到当前解析软链接后的实际目录。读取快照和事务返回前重新观察文件系统，只有存在 `SKILL.md` 的目录进入映射。旧状态无需迁移。

前端优先按该映射去重。存在映射但某个 ID 未解析成功时，该记录保持独立候选。旧后端与浏览器演示按精确的外部路径，或完整包摘要与成员相对路径组合识别，不比较目录内容。

完整包摘要不同、共享依赖不同，或相同字节位于两个独立目录时，仍是不同候选；本次不做物理去重。

## 分发计划

手动分发遇到同名的其他记录绑定时，实时比较绑定实体与所选 Skill 实体。如果实际目录相同，则复用已有绑定并补充手动引用，不要求来源切换、不改原 Skill ID、版本、跟随策略和恢复信息。已有链接异常等检查仍然有效。

实体不同时保留现有来源切换确认流程。预设和本地来源操作仍按各自身份处理，避免将不同的更新关系当作相同引用。

## 实体与版本的展示

- 当前实体以整包快照标识和成员相对路径，或实际本地目录标识。同一实体使用同一标签，不使用某条来源记录的版本号代表实体。
- 详情单独列出同一实体的来源记录及“来源记录版本”，保留历史值，不改写记录或推断内容版本一致。
- 分发候选展示实体标识；切换预览分别标注“分发记录版本”和“来源记录版本”。回滚仍按真实快照选择，历史版本号仅为辅助追溯。
- 路径无法解析时显示“实体位置未确认”，不宣称已确认同一实体。

## 验证范围

- 前端生产构建、现有 10 项前端测试、核心 79 项测试、桌面编译、DTO 同步与格式检查。
- 隔离 CLI：观察缓存刷新、相同快照的不同记录、指向同一实体的软链接别名复用绑定，以及不同目录的相同内容仍要求确认切换。
- 浏览器隔离演示：卡片和表格显示、同一实体直接分发、批量去重、不同实体候选和目标预选。
- 未修改真实 Skill 库数据；原生桌面点击验收与发布尚未进行。
