# 列表弹窗固定选项区

分发与扫描流程保持标题、输入及底部选项/按钮可见，只有数据区域滚动。

- AppDialog 新增 options 插槽，与可滚动 body 和按钮 footer 同级。
- 分发的 Skill/目标选择区各自滚动；预览列表滚动，接管选项和错误在底部固定。
- 预设文件夹扫描的成员/移除项滚动；新增成员策略和同步按钮固定。
- Git 集合的成员/移除项滚动；导入去向、预设选择、新增策略和同步按钮独立固定。
- 本地来源名称、路径、扫描按钮固定；成员滚动，风险提示与保存按钮固定。
- 滚动或切换布局不清空选择，不影响 API、分发权限或保存逻辑。

验证应使用长列表检查选项和按钮初始可见，以及滚动前后坐标不变；同时检查短列表与较小窗口。

全局提示、扫描警告和操作错误使用标题下的独立提示区，随列表滚动保持可见。Git 扫描结果摘要和问题提示同样与成员列表分离。每个成员自身的错误仍贴近该成员展示；来源移除项列表属于可选择的数据，整体移除数量和规则在固定提示区展示。多条长提示仅在提示区内部滚动，不挤出确认按钮。

## 预设编辑操作区域（2026-10-15）

预设编辑使用最大 1200px 宽的工作区，名称与描述固定在顶部，成员选择/文件夹扫描/Git 导入位于左栏，来源包和已选成员位于右栏。取消原成员列表 280px、已选区域 150px/矮窗口 68px 的固定高度上限，改为利用剩余高度独立滚动；已选成员默认展开，名称可完整换行。滚动条右侧预留操作间距，避免 macOS 覆盖式滚动条挡住移除按钮。

预设中的 Git 导入默认收起可选的分支/子目录设置，展开与收起保留输入；其他 Git 导入入口维持原布局。小于等于 900px 的窗口改为上下排列并允许工作区滚动，成员区保留最低可用高度。保存按钮始终固定在弹窗底部。

验证使用浏览器独立示例与临时构造的 80 项 Git 预览/60 项已选成员，覆盖成员选择和移除、搜索、左右独立滚动、切换来源、可选设置展开与收起及 1000×680/800×700 窗口布局。Git 预览使用模拟数据，不代表真实仓库联网导入或原生保存验收。
