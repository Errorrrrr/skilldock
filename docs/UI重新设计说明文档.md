# SkillDock 技术栈与功能模块说明

---

## 一、技术栈

| 层次 | 核心技术 / 依赖 | 说明与用途 |
| :--- | :--- | :--- |
| **应用外壳 & 后端引擎** | **Tauri v2** + **Rust** | 跨平台轻量桌面容器。底层 Rust 引擎负责文件系统监听、符号软链（Symlink）原子管理、基于内容哈希的不可变对象快照存储（Git-like Objects 结构）、事务操作与备份。 |
| **前端框架 & 构建** | **Vue 3.5** + **TypeScript 5.9** + **Vite 7.3** | 前端采用 Composition API 与 `<script setup lang="ts">` 开发，通过 Vite 快速构建。 |
| **样式体系** | **Tailwind CSS v4** | 原子化样式，搭配 CSS 变量（`--panel`, `--surface`, `--line`, `--blue` 等）支持明暗主题。 |
| **组件无样式原语** | **Reka UI** (`reka-ui`) | 提供 Dialog、Sheet（抽屉）、Tooltip、RovingFocus 等无样式的可访问性底层交互组件。 |
| **数据表格** | **TanStack Table v8** (`@tanstack/vue-table`) | 用于数据表格的驱动与渲染。 |
| **图标库** | **Lucide Vue Next** (`lucide-vue-next`) | 界面标准线性图标库。 |
| **状态与路由** | **Pinia 3** + **Vue Router 4** | 全局响应式状态管理（以系统快照 `Snapshot` 为单一数据源）与 Hash 路由模式。 |
| **表单与验证** | **Vee-Validate 4** + **Zod** | 表单输入验证与 Schema 校验。 |
| **文档渲染** | **Markdown-it** + **DOMPurify** | 负责 Skill 说明文档（`SKILL.md`）的 Markdown 渲染与安全清洗。 |

---

## 二、系统功能模块说明

系统由三大功能域、共 8 个页面/板块组成：

```
├── 资产库
│   ├── 1. Skill 库 (/library)
│   ├── 2. 发现与安装 (/discover)
│   └── 3. 预设套件 (/presets)
├── 连接与工作空间
│   ├── 4. 归集已有 Skill (/import)
│   ├── 5. 分发目标 (/targets)
│   └── 6. 来源与更新 (/updates)
└── 系统保障
    ├── 7. 任务与记录 (/tasks)
    └── 8. 设置与备份管理 (/settings)
```

---

### 1. Skill 库 (`/library`)
*本模块是整个应用的核心资产总览页面。*
- **双视图切换（Grid 卡片 / Table 列表）**：工具栏支持在**卡片网格**与**表格列表**之间一键切换，偏好自动保存至本地。卡片网格更具资产感与包裹感，适合浏览 2~3 行完整描述；表格列表适合高密度管理与工具状态横向快速比对。
- **资产检索与过滤**：支持按 Skill 名称/描述全局搜索，按来源类型（Git / 本地）、分发目标（已安装至哪个工具）进行多维度筛选。
- **状态与软链标记**：直观展示版本号、本地跟随状态，以及**已在哪些工具中使用（以工具名 Tag 集合展示，如 Cursor、Claude Code 等，悬停查看具体软链物理路径）**。
- **一键分发 / 解绑**：无论卡片还是表格均支持直接点击工具胶囊一键分发/解绑，并提供锁定状态保护与操作提示。
- **右侧详情抽屉（SkillDetailSheet）**：
  - Markdown 渲染完整的 `SKILL.md` 文档；
  - 查看已分发到的所有工具软链状态，支持反向解绑；
  - 查看历史快照版本并支持版本回退。

---

### 2. 发现与安装 (`/discover`)
*本模块提供公共/团队 Skill 市场的浏览与安装入口。*
- **多市场源切换**：支持在官方市场、自定义 GitHub/GitLab 仓库索引或私有站点之间切换。
- **市场卡片流**：展示 Skill 的名称、版本、介绍、协议兼容状态，以及“未安装 / 已入库”状态。
- **一键安装分发**：点击安装后，将 Skill 下载并保存至中央统一库，同时支持在弹窗中直接勾选目标工具一键建立软链。

---

### 3. 预设套件 (`/presets`)
*本模块用于将多个 Skill 组合打包为固定场景/业务的套件，实现跨工具批量分发。*
- **预设卡片列表**：展示预设名称、描述、所含 Skill 数量、关联的本地包，以及已应用到的目标工具。
- **预设编辑与构建（PresetEditorDialog）**：
  - **从统一库勾选**：从已有 Skill 中搜索并勾选加入预设；
  - **从本地文件夹扫描（包同步）**：扫描外部文件夹中的多个 Skill 作为整体包同步，自动识别使用位置工具名 Tag；
  - **旧归集迁移预检**：以**双卡片切换**形式，分别查看该目录下【需恢复来源（含旧软链/非独立实体）】与【可直接登记（纯净实体）】两个独立列表，标注实际物理路径与原因。
- **一键应用与自动跟随**：将预设一键批量分发给选定的 Target 工具，并支持开启“自动跟随（后续预设新增 Skill 自动分发到该工具）”。

---

### 4. 归集已有 Skill (`/import`)
*本模块是核心向导工作流，将各 AI 工具中零散存放的旧 Skill 搬迁入中央库，并将原位置替换为软链。*
- **四步向导流程**：
  1. **选择扫描范围**：自动发现本机已安装工具的默认 Skill 目录（Cursor、Claude、Antigravity、Codex 等），支持追加自定义文件夹；
  2. **审阅扫描结果**：
     - **双状态卡片分列**：顶部通过两张卡片切换查看**【可以归集（独立完整实体，带勾选框与全选）】**和**【不可归集（已有软链、断链、外部管理，无勾选框并展示保护说明）】**两个独立表格；
     - **同名冲突处理**：为同名不同内容的条目指定处理策略（保留新版、重命名、跳过）；
  3. **确认归集计划**：汇总待入库清单、将被替换为软链的原路径，提示系统将自动生成隐藏原子备份；
  4. **执行与回执**：执行复制、哈希校验、软链替换，展示最终结果与失败项重试入口。

---

### 5. 分发目标 (`/targets`)
*本模块负责维护和管理各个 AI Agent / IDE 工具的接入环境。*
- **双层范围划分**：
  - **用户全局级（User Scope）**：如 `~/.cursor/skills`、`~/.claude/skills` 等全局生效目录；
  - **项目工程级（Project Scope）**：如特定代码仓库根目录下的 `.cursor/skills`。
- **目标管理**：自动探测本机已安装的工具目录，支持自定义新增工具目录、指定工具类型、修改别名或移除目标。

---

### 6. 来源与更新 (`/updates`)
*本模块负责监控绑定的外部更新源，保障技能与上游同步。*
- **更新源追踪**：管理已绑定的 Git 远程仓库或本地源码目录，配置检测策略（关闭 / 仅通知 / 自动拉取）。
- **待处理更新卡片**：聚合出现新版本的技能条目，展示版本对比与 Commit 差异，支持一键更新并自动重链刷新已分发的工具。

---

### 7. 任务与操作记录 (`/tasks`)
*本模块提供操作日志审计与异常恢复能力。*
- **操作流水审计**：记录系统发生过的所有关键操作（归集、分发、解绑、更新），展示执行状态、耗时、涉及路径与时间戳。
- **意外中断恢复**：当归集或迁移等任务因崩溃中断时，提供可恢复任务卡片与重试入口。

---

### 8. 系统设置与备份管理 (`/settings`)
*本模块负责底层物理配置与数据安全防护。*
- **统一存储根目录（Storage Root）**：查看和更改中央库物理路径（默认 `~/.skilldock`）。
- **工具目录规则偏好（Agent Profiles）**：查看和自定义各已知 AI 工具的默认识别路径模式。
- **备份管理器（BackupManager）**：
  - 按批次查看历史快照；
  - **一键还原原位置**：将软链恢复为独立实体文件，清理统一库无用实体。
- **常规桌面偏好**：开机自启、关闭时最小化到系统托盘（支持后台守护与托盘菜单快速查看）。
