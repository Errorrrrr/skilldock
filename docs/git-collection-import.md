# Git 集合导入

## 目标和行为

- 仓库 URL 或 GitHub/GitLab tree URL 可预览。后端统一解析仓库、引用、子目录；复杂带斜线分支可明确填写引用。
- 预览获取固定 commit，返回所有成员、内容变化、来源移除和依赖问题；不写入库成员、不安装和分发。
- 确认根据预览 token、库 revision、内容摘要校验；整仓共享资源入快照，只在所选子目录内登记 Skill。
- 每个 Git 来源对应远程同步包。库只记录所选成员，快照保留完整共享资源。可新建预设、加入现有预设或仅入库；关闭新增成员订阅后，不自动纳入未选成员。
- 同 URL、引用、子目录重复导入复用来源及成员 ID。源实体来自受管缓存；远程包不冒充用户本地包。
- 更新沿用来源更新任务和包订阅：自动加入控制新增；删除默认保留，确认移除只撤销当前预设 claim；固定目标和其他引用保留。
- Git CLI 旧 import_git 入口也注册同步包，返回格式仍为 Snapshot。
- 预设编辑器提供从 Git 集合入口，包入库与预设草稿保存分开。不会自动开启定时任务或向新工具分发。

## 验证

使用隔离配置与本地 Git fixture 验证取消预览、子目录与共享资源、选择预设、重复身份、后续新增/移除、跟随和固定分发、陈旧预览及篡改预览。
前端用模拟 API 的浏览器验证 Git 预览选择、UI 库下拉及预设保存请求。
真实示例仓库仅在临时隔离库验证，不操作用户库、预设和工具目录。

早期版本验证记录（当时库记录全部成员，已被当前选择范围规则替代）：核心现有测试 57 项通过，前端生产构建、桌面 Rust 检查、生成类型一致性通过；隔离 Git 生命周期脚本与两个入口的浏览器模拟交互通过。真实 drama-skills 仓库在 commit `9e78a57696d4049101e1b293da28baf62efb6b10` 识别 11 个成员，验证了全部入库、选择其中 2 个加入预设。独立审查发现的无关成员锁被升级问题已修复并复核。
