# 预设包差异同步

## 需求与实现

再次扫描已登记的原包，需要识别新增、变更与移除，点击同步实际更新内容，保留原文件夹及旧快照。

- 扫描返回成员变化类型和已移除成员列表，比较当前源成员和库成员内容。共享资源随作用域整包快照保存。
- 已登记包根据各 scope.originPath 读取原目录，保留 Git 仓库边界，不拉取或改写用户 checkout。
- 在一次库事务中复制快照、保留既有成员 ID、增加新成员、记录 missingMemberIds；缺失成员保留旧快照和库记录。
- 已保存预设自动加入设置决定新增成员是否进入预设；排除项不重新加入。已在预设中的缺失成员先保留。
- 同步完成后推进已跟随预设的目标。目标冲突保留旧状态和可重试错误，不自动接管外部安装。
- 编辑器展示移除复选框，默认不选。同步按钮将确认移除放入编辑草稿，保存时才持久化成员和排除项。
- 保存后同步跟随目标。撤销的只是该预设 claim；其他预设、手动分发和固定版本不变。旧对象由现有引用检查及清理流程管理。
- 全空包可同步；编辑既有预设可保存空成员列表，执行仅撤销引用而不调用空分发。

## 验证场景

隔离脚本 `/tmp/sd-sync-flow.py`：A/B 变为 A/C；自动加入和固定选择；未保存移除保留 B；确认保存移除 B 时保留其他预设和 manual claim；固定目标不变；重复同步不产生重复 ID；旧 revision 拒绝；空包和空预设；旧实体保留。

隔离脚本 `/tmp/sd-rescan-check.py`：Git 包、嵌套仓库、共享远程的不同检出目录重复扫描身份；真实同名不同来源仍提示冲突。

浏览器脚本 `/tmp/sd-sync-browser.cjs`：以模拟 API 验证差异标签、自动加入关闭时不选择新成员、移除默认不勾选、确认移除延迟到保存，以及保存请求的订阅范围。截图 `/tmp/sd-sync-diff-ui.png`。该验证不代表对真实原生窗口进行了 UI 操作。

没有自动操作用户真实包、预设或分发。代码未提交、未推送。
