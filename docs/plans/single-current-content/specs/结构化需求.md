# 单一当前内容

状态：用户已授权实现、合入 main 并触发发布；不监听发布结果。

1. 一个明确身份的 Skill 只有一份当前内容，按名称直接浏览；内部记录与包实体收纳在 `.skilldock`。
2. 取消用户侧历史版本选择、目标固定版本和预设内容锁定。所有管理目标使用当前内容，预设仅保存成员。
3. 更新前验证完整包依赖、现有链接和目标；通过文件事务切换所有引用。失败保留原内容，未完成事务可恢复。
4. 每个独立更新来源最多保留一次更新前恢复内容；同一包的成员一起撤销更新，防止共享资源不一致。备份不作为可分发版本。
5. 相同完整内容及依赖复用存储并记录来源；同名不同内容需明确选用、替换或独立保留，禁止仅凭名称合并。
6. 旧库先预览默认内容、受影响工具和预设；确认后迁移。应用升级本身不自动删除真实库内容。
7. 已完成任务日志不再无限保护历史对象。当前内容、最近恢复备份、未完成事务、原目录恢复备份、外部引用均继续受保护。
8. 清理通过现有引用检查和可恢复任务执行。重复执行不增加副本；失败清理可重试且不撤销已成功更新。
9. 完成隔离文件验证、编译和前端交互验证；提交并合入主分支后推送新版本标签，只确认一次工作流触发。
