# Skill 库优化接口与数据契约（拟新增）

> 2026-09-21 状态补充：本方案中的稳定身份、默认版本、迁移及回收设计仍待评审。当前已完成的同实体分发与版本展示见 [实体分发说明](../../../specs/entity-distribution.md)，重加目标自动绑定见 [目标绑定恢复](../../../specs/target-binding-recovery.md)。本草案不代表这些后续设计已经实现。

## 1. 状态模型

现有 `Skill` 继续代表来源成员记录，`Source` 代表来源配置，`Binding` 保留实际安装和引用语义；新增模型用来承载用户确认的逻辑身份，不删除旧记录。

```ts
type LibraryEntry = {
  id: string                  // UUID；独立于名称、路径、摘要
  displayName: string
  directoryName: string       // 持久化的可读入口名；不随刷新变化
  recordIds: string[]         // 指向已有 Skill.id，迁移时每条恰好归属一个 entry
  defaultRecordId: string | null
  updateSourceId: string | null // 默认更新来源，必须来自本 entry 的合法来源关系
  status: 'ready' | 'needs_choice'
}
type LibraryIndex = {
  version: 1
  entries: LibraryEntry[]
}
type LibraryVariant = {
  recordId: string
  sourceId: string
  sourceLabel: string
  originKind: 'remote' | 'local_snapshot' | 'external_reference'
  digest: string | null
  relativePath: string
  externalPath?: string
  comparison: 'same_runtime' | 'different' | 'unknown'
  comparisonReason: string
  bindingIds: string[]
}
type LibraryEntryDetail = {
  entry: LibraryEntry
  variants: LibraryVariant[]
  historyOrigins: { sourceId: string; label: string; path?: string }[]
}
```

- `Snapshot` 在新数据格式中增加 `libraryIndex`；正式迁移采用尚未使用的下一个 `schemaVersion`（当前为 2，拟为 3）。迁移前先核对是否已被其他需求占用。
- 缺少索引的旧格式允许只读预览；不得在普通 snapshot 读取时落盘迁移。
- `defaultRecordId` 只选择今后新分发使用的记录；预览执行期间用完整摘要和路径固定该版本，不随对象更新漂移。
- `updateSourceId` 为空即无默认自动更新源；不是把所有历史收录目录加入自动更新。
- 物理对象仍使用现有摘要路径；`same_runtime` 是有证据的运行内容等价，不等于同名，也不等于默认版本选择授权。

## 2. 预览与执行

```ts
type LibraryDecision =
  | { kind: 'merge'; entryIds: string[]; keepEntryId: string; defaultRecordId: string; updateSourceId: string | null }
  | { kind: 'set_default'; entryId: string; defaultRecordId: string; updateSourceId: string | null }
  | { kind: 'split'; entryId: string; groups: { recordIds: string[]; displayName: string }[] }
type LibraryPlan = {
  token: string
  expectedRevision: number
  expiresAt: string
  affectedEntries: string[]
  affectedRecords: string[]
  preservedBindings: string[]
  conflicts: { code: string; message: string; entryId?: string }[]
  comparisonSummary: { same: number; different: number; unknown: number }
  estimatedReclaimableBytes: number // 只有独立清理计划可大于 0；身份合并始终为 0
}
type LibraryOperationResult = {
  snapshot: Snapshot
  taskId: string
  browseStatus: 'ready' | 'needs_rebuild'
}
```

| action / 前端签名 | 请求 | 响应 | 核心约束 |
| --- | --- | --- | --- |
| `preview_library_migration` / `previewLibraryMigration()` | 无 | `LibraryPlan` | 只读计算映射、冲突及版本兼容条件 |
| `apply_library_migration` / `applyLibraryMigration(token, expectedRevision)` | `token: string, expectedRevision: number` | `LibraryOperationResult` | 备份索引、事务提交；不切现有工具链接 |
| `get_library_entry` / `getLibraryEntry(entryId)` | `entryId: string` | `LibraryEntryDetail` | 汇总记录、默认源和实际安装版本 |
| `preview_library_decision` / `previewLibraryDecision(decision)` | `decision: LibraryDecision` | `LibraryPlan` | 预览合并/拆分/默认版本，不能包含隐式安装切换 |
| `apply_library_decision` / `applyLibraryDecision(token, expectedRevision)` | `token: string, expectedRevision: number` | `LibraryOperationResult` | 执行服务器保存的决定，不能由客户端重传更换范围 |
| `rebuild_library_view` / `rebuildLibraryView(expectedRevision)` | `expectedRevision: number` | `{ taskId: string, ready: number, blocked: number }` | 仅操作应用拥有且与清单一致的入口，逐项可重试 |
| `get_library_storage` / `getLibraryStorage()` | 无 | 下述存储统计 | 本地只读统计，无自动删除 |

存储统计：`{ logicalEntryCount, recordCount, objectCount, objects: [{digest, logicalBytes, allocatedBytes: number|null, reason: 'current'|'pinned'|'recovery'|'history'|'unknown', referrers: string[]}], inspectedRevision }`。一个对象可有多种引用，返回主分类并列出全部引用；`logicalBytes` 不是可释放空间。

## 3. 复用接口

- 真实工具切换继续通过现有 `plan` / `distribute` 与 `replaceBindingIds`，必须重新获取执行时的 `revision`；本方案的身份操作 token 不具有工具切换权限。
- `apply_preset` / `apply_local_source` 保留自己的引用范围、原入口名和替换授权语义。
- 实体清理复用 `preview_object_cleanup` / `cleanup_objects` / `retry_object_cleanup`；加入新索引与迁移清单引用后重新预览，不能使用旧版清理结果。
- 现有接口签名不删除、不重命名。旧客户端可继续使用原记录级动作；新 UI 的 `entryId` 不允许直接充当旧 `skillId`，必须通过索引解析并在事务内验证。
- 所有入口共用 `control.lock` 和完整状态 `revision`。同一 token 重试返回原 task 结果；执行过期、摘要变更、来源/绑定变更一律重新预览。

## 4. 错误结果

新动作错误统一为 `{ code, message, retryable, taskId? }`；旧动作暂保留原错误形式，由前端适配，不破坏旧 CLI。

| `code` | 触发条件 | UI 处理 |
| --- | --- | --- |
| `PLAN_STALE` | revision、文件、链接或计划有效期发生变化 | 保留选择，要求重新预览 |
| `IDENTITY_CONFLICT` | 跨身份合并无用户决定、记录缺失或归属重复 | 展示冲突记录，禁止执行 |
| `DEPENDENCY_UNVERIFIED` | 共享/包外依赖等价无法证明 | 保留副本，禁止物理去重；允许查看差异 |
| `SOURCE_INVALID` | 默认源不属于条目或不是合法更新位置 | 引导选择/配置来源 |
| `PATH_OCCUPIED` | 可读入口被非应用管理文件占用 | 不覆盖，提供改名或手动处理 |
| `RECOVERY_REQUIRED` | 有未完成事务 | 引导恢复，暂停其他写入 |
| `SCHEMA_UNSUPPORTED` | 应用版本不支持该库格式 | 禁止写入，提示兼容版本或备份恢复 |
